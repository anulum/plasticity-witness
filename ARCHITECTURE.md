# Architecture

## Current executable surface

Repository validation tooling, dedicated tests, workflow definitions and native documentation are implemented. No learning oracle, protocol runner, capture adapter, comparison package or report command is installed. Domain capability, claim and qualified-format inventories remain empty.

## Intended data flow

A prior complete protocol and numerical realization drives an actual source-owned implementation and an independently justified reference. Software or qualified capture retains every required initial, intermediate and final state. Analysis compares every update or an explicitly supported distribution, retaining the earliest discrepancy and missing observations. Report construction uses installed shared evidence operations. A separate consumer verifies the exact report and references; Studio renders the existing result.

## Ownership

Plasticity Witness owns the independent reference, protocols, comparison and report. SC-NeuroCore and a later extracted learning component retain actual rule implementations. Loop Timing Witness owns capture and timebase; Evidence Manifest Toolkit owns shared evidence operations. Arithmetic and source suitability are separately owned supporting results. Reliability rates and generic storage retain their respective owners.

## Interpretation

Source methods can differ in arithmetic, event order, reset, units and random state. They are not interchangeable counterparts. Matching weight alone does not prove matching updates or encoded state. Read [the documentation architecture](docs/ARCHITECTURE.md) for the planned full report and numerical boundaries.
