# Decision: independent observation of source-owned learning rules

## Context

Rule implementations can differ in numerical representation, event order, state, reset and random-stream consumption. Reusing an implementation as its own oracle or comparing only final weight cannot establish independent learning-rule agreement.

## Decision

Plasticity Witness owns independently justified references, complete prior protocols, comparison and reports. SC-NeuroCore and a future extracted learning component retain the implementations under test. Loop Timing Witness supplies capture and timebase; installed Evidence Manifest Toolkit supplies shared evidence operations. Separately owned arithmetic and randomness evidence supports only its actual admitted scope. Studio renders existing results.

## Consequences

Repository tooling can be qualified before a learning experiment exists. Exact, distributional, software, RTL and measured fabric scopes remain distinct. Full initial and intermediate state, numerical operation points, complete event and observation populations and real independent consumers are required for learning qualification. Neither source names nor sealed bytes alone prove numerical validity.
