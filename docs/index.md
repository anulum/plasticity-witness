# Plasticity Witness

This repository is preparing an independent learning-rule comparison tool. Its current executable surface is repository validation tooling. It has no installed learning-rule comparison package, public plasticity runner or qualified learning report.

Plasticity Witness is part of the **SC Neuromorphic Computing Systems** group (SC-NEUROMORPHIC-COMPUTING-SYSTEMS). The [group and project map](https://github.com/anulum/sc-neurocore/blob/main/docs/ecosystem.md) shows the whole programme and where this repository sits in it.

The intended workflow retains complete protocols, numerical schedules, state and observation populations. Bit-exact and supported distributional comparisons remain separate, as do software, RTL and measured fabric evidence. An unavailable oracle, state or capture cannot become a matching result.

Read [Architecture](ARCHITECTURE.md), [validation tooling](validation-tooling.md), [data boundaries](THREAT_MODEL.md) and the [repository boundary decision](adr/0001-repository-boundary.md).
